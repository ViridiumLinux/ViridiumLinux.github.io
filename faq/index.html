The basics

General

What is Viridium Linux?

An extremely fast, speed-oriented minimal Linux system that anyone can use. It has its own repo for rolling release updates, plus full Arch repo and AUR support.

Why is there no desktop after installing?

The install is deliberately minimal, with no desktop environment or window manager, to keep the system fast. Add the one you want with vbuild, then enable its display manager with systemd. For example, for GNOME, as root:

root
# vbuild -S gnome\n# systemctl enable --now gdm
Which kernel should I choose?

vinstall offers four. linux is the mainline kernel, linux-lts favours long-term stability, linux-zen is tuned for responsiveness, and linux-hardened focuses on security.

Is Viridium rolling release?

Yes. Keep your system current with vbuild -Syu.

Before you install

Hardware

What are the minimum requirements?

10 GB of storage, 1 GB of RAM and a fairly modern x86 CPU such as an Intel Core or AMD Ryzen.

Does Viridium run on ARM?

Not yet. ARM support is a work in progress and will be finished in the future.

Do I need a dedicated graphics card?

No. An AMD GPU is recommended over NVIDIA because NVIDIA support on Linux is not great, but a dedicated card is not required.

When something goes wrong

Troubleshooting

vbuild says it cannot find a package

Check the spelling and search with vbuild -Ss name. If it still fails, run vbuild -Syu to refresh the repos and upgrade, then try again.

An AUR package failed to build

Read the end of the build output for the error. Run vbuild -Syu and retry, since outdated dependencies are a common cause, and check the comments on the package\'s AUR page.

The system freezes or feels unstable

Less than 1 GB of RAM can cause instability. If you have less, use a lightweight window manager instead of a full desktop environment.

I have NVIDIA graphics problems

Update with vbuild -Syu and install the NVIDIA driver that matches your kernel: nvidia for linux, nvidia-lts for linux-lts, or nvidia-dkms for linux-zen and linux-hardened. An AMD GPU avoids most of these issues.

Removed packages left dependencies behind

Use vbuild -Rns package instead of -R, which also deletes the dependencies.

Where do I report a bug?

Open an issue on the GitHub issue tracker.
