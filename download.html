Next steps

Install it

  1. Write the ISO to a USB drive with balenaEtcher or Ventoy (see below).
  2. Boot from the USB and log in as root.
  3. Run vinstall and follow the prompts for kernel, timezone, username and password.

balenaEtcher

The simplest option. Choose the ISO, choose your USB drive, then click Flash. Works on Windows, macOS and Linux. Get balenaEtcher

Ventoy

Install Ventoy to the USB drive once, then copy the ISO onto it like any file and pick it from the boot menu. One drive can hold several ISOs. Works on Windows and Linux. Get Ventoy

Back up the drive first. Both tools erase the USB drive when you set it up, so check you've picked the right one.

After installing, read the vbuild guide to add software, or the FAQ if you get stuck.
