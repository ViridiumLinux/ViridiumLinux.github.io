Install Viridium Linux

<html><head></head><body><h1>Viridium Linux</h1><p>Viridium Linux is a minimal, Arch-based Linux distribution.</p><p>It uses the Arch Linux package ecosystem, including the official repositories and the AUR, while providing its own installer and system-management tools.</p><p>Viridium is designed to keep the parts of Arch that are useful and familiar while making a few parts of the system simpler to use.

<h2>vbuild</h2><p><code inline="">vbuild</code> is the main package manager in Viridium.</p><p>Its primary purpose is combining the <strong>official Arch repositories and the AUR</strong> into one package-management interface.</p><p>On a normal Arch installation, package management commonly looks like:</p><pre><code class="language-text">pacman → official repositories yay → AUR </code></pre><p>Viridium instead uses:</p><pre><code class="language-text">vbuild → official repositories + AUR </code></pre><p>This means you don't have to switch between two different programs depending on where a package comes from.</p><p><code inline="">vbuild</code> is also designed around a faster workflow than the traditional <code inline="">pacman</code> + AUR helper setup.</p><p>Its command syntax is intentionally similar to <code inline="">pacman</code>, so existing Arch users don't have to learn an entirely different command structure.</p><h2>vinstall</h2><p><code inline="">vinstall</code> is the Viridium installer.</p><p>It handles the initial system setup, including:</p><ul><li><p>Disk configuration</p></li><li><p>Filesystems</p></li><li><p>Kernel selection</p></li><li><p>Hostname</p></li><li><p>Timezone</p></li><li><p>User creation</p></li><li><p>Base package installation</p></li><li><p>EFI configuration</p></li><li><p>Bootloader installation</p></li></ul><p>It can either wipe an entire disk or install using existing partitions.</p><h2>viridium</h2><p><code inline="">viridium</code> is the general system-management command.</p><p>It provides commands for things such as:</p><pre><code class="language-bash">viridium update viridium clean viridium info viridium doctor </code></pre><p>It also manages the temporary unlocking of <code inline="">pacman</code> and <code inline="">yay</code>.</p><h2>Package management</h2><p>Normal package management should be done through <code inline="">vbuild</code>.</p><p>For example:</p><pre><code class="language-bash">vbuild -S firefox </code></pre><p>Update the system with:</p><pre><code class="language-bash">vbuild -Syu </code></pre><p>Search for a package with:</p><pre><code class="language-bash">vbuild -Ss firefox </code></pre><p>See [[vbuild]] for the full command reference.</p><h2>Installation</h2><p>Boot the Viridium live environment and run:</p><pre><code class="language-bash">vinstall </code></pre><p>See [[Installation]] for the complete installation procedure.</p><h2>Getting help</h2><p>For system diagnostics:</p><pre><code class="language-bash">viridium doctor </code></pre><p>For command help:</p><pre><code class="language-bash">viridium help </code></pre><p>The [[Troubleshooting]] page covers common problems and their solutions.</p><h2>Wiki pages</h2><h3>Installation</h3><ul><li><p>[[Installation]]</p></li><li><p>[[Boot and UEFI]]</p></li></ul><h3>Package
