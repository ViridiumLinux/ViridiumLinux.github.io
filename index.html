Viridium Linux

If it's not broken, don't fix it.

An extremely fast, speed-oriented system that anyone can use. A very minimal install, a pacman-like package manager, and full Arch and AUR support out of the box.

Before you begin

System requirements

To run Viridium Linux you will need the following at a minimum:

10 GB
Storage
1 GB
RAM. Anything below this may cause instability and issues.
x86
A fairly modern CPU, e.g. Intel Core or AMD Ryzen.
No ARM
Not supported yet. It is a work in progress and will be finished sometime in the future.
Graphics: An AMD GPU is recommended over an NVIDIA GPU, as NVIDIA's support on Linux isn't great. You do not need a dedicated graphics card to run Viridium; it isn't a requirement.
Setup

Installation

Installing Viridium Linux is very easy. Need the ISO? Head to the download page.

  1. Boot into the live environment and log in as root.
  2. Run the installer command shown below.
  3. Follow the prompts to finish setup.
root@viridium-live
# vinstall

The command walks you through the installation, letting you choose:

  • Your kernel
  • Your timezone
  • Your username
  • Your password

The rest of the installation is pre-configured to install a very minimal system, without any desktop environment or window manager. The point of a minimal install is Viridium's goal: an extremely fast, speed-oriented system that anyone can use.

Packages

Package manager

The package manager in Viridium Linux is named vbuild. It is a pacman-like package manager, for ease of use, and it uses the same flags as pacman.

FlagWhat it does
-SInstalls packages
-RnsRemoves packages and its dependencies
-RRemoves packages
-SyuUpdates repos and packages
vbuild
$ vbuild -Syu
$ vbuild -S <package>
$ vbuild -Rns <package>

Want every flag and AUR examples? Read the full vbuild guide, or check the FAQ.
