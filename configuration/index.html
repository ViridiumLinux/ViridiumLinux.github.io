Configuration

Viridium uses the standard Linux configuration tools and system components wherever possible.

Hostname

The hostname can be viewed with: 
hostnamectl
The hostname is normally configured during installation.

Timezone

The current timezone can be checked with: 
timedatectl
The timezone is selected during installation.

Users

The initial user is created by vinstall. The account is configured for sudo. Normal Linux user-management tools can be used after installation.

Services

Viridium uses systemd for service management. Check a service with: 
systemctl status service-name
List failed services: 
systemctl --failed
List enabled services: 
systemctl list-unit-files --state=enabled

Network configuration

Network configuration is handled by NetworkManager. See Networking.

Package configuration

Packages should normally be installed and removed through: 
vbuild
Direct pacman and yay access is locked by default. See Package Management.
