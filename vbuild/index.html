vbuild guide

Everything you need to install, update and remove software on Viridium Linux.

Overview

One command, three sources

vbuild is Viridium's pacman-like package manager and uses the same flags as pacman. -S checks the Viridium repo, the Arch repos and the AUR automatically, so you never need to know where a package lives.

Reference

Flags

FlagWhat it doesExample
-SInstalls packagesvbuild -S htop
-SyUpdates reposvbuild -Sy
-SyuUpdates repos and packagesvbuild -Syu
-RRemoves packagesvbuild -R htop
-RnsDeletes packages and dependenciesvbuild -Rns htop
-SsSearches for packagesvbuild -Ss browser
-QLists installed packagesvbuild -Q
-QiShows details of an installed packagevbuild -Qi htop
In practice

Examples

Update everything, install two packages from the repos, then install and remove a package from the AUR:

vbuild
$ vbuild -Syu
$ vbuild -S neovim htop
$ vbuild -S google-chrome   # from the AUR
$ vbuild -Rns google-chrome
Update with -Syu. Viridium is rolling release. Avoid running vbuild -Sy on its own and then installing something; refresh and upgrade together with -Syu to prevent partial upgrades.
Community packages

Using the AUR

There is nothing extra to set up. If a package is not in the Viridium or Arch repos, vbuild -S finds it in the AUR and builds it for you.

AUR packages are submitted by users and built from source, so builds can take a while and quality varies. Read a package's PKGBUILD on its AUR page before installing it.
