# Viridium-Linux
An arch-based linux distro with a faster package manager (vbuild) - which combines the AUR and the Pacman repos together, into one unified command.

Commands:

vinstall (installs the OS from the live inviroment)

vbuild (package manager, uses simmilar flags to pacman, -S for install, -Rns for remove, -Yc to purge orphans, -Syu to update.)

viridium help (Gives the list of command flags for the viridium command, like viridium update, or viridium cleaner.)
