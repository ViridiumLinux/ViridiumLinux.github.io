# Viridium Linux

Viridium is a minimal, Arch-based Linux distribution with its own installer and package management tools.

It uses the Arch repositories and AUR, while `vbuild` combines both into one package manager with a faster package-management workflow.

## Features

- Arch-based
- Official repositories + AUR through `vbuild`
- Custom installer
- `viridium` system management utility
- UEFI / systemd-boot
- NetworkManager
- Minimal base system

## Installation

Boot the Viridium live environment and run:

```bash
vinstall
```
See the [wiki](https://github.com/vDelta01/Viridium-Linux/wiki) for more info.
